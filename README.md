# GitHub Copilot Chat Cookbook Examples

This repository contains organized examples from the [GitHub Copilot Chat Cookbook](https://docs.github.com/copilot/tutorials/copilot-chat-cookbook). Each example includes:

- A `prompt.txt` file containing the exact prompt to use with GitHub Copilot Chat
- A corresponding code file demonstrating the example

## Structure

The examples are organized into the following categories:

### Debugging Errors
- **fix-json-syntax-error** - Fix syntax errors in JSON files
- **handle-rate-limiting** - Implement proper rate limiting and retry logic

### Functionality 
- **explore-feature-implementations** - Design new features and functionality
- **incorporate-feedback** - Analyze and categorize user feedback

### Refactor Code
- **improve-variable-names** - Make code more readable with better naming
- **fix-lint-errors** - Address linting issues and code quality problems
- **performance-optimization** - Optimize code for better performance
- **improve-design-pattern** - Implement better architectural patterns
- **refactor-data-access-layer** - Fix security issues and improve data access
- **decouple-business-logic** - Separate concerns for better maintainability

### Documenting Code
- **explain-complex-logic** - Add clear documentation to complex code
- **legacy-cobol-documentation** - Document and understand legacy systems
- **update-documentation** - Fix and improve existing documentation

### Testing Code
- **create-unit-tests** - Generate comprehensive unit tests
- **create-mock-objects** - Create proper mocks for testing

## Usage

1. Navigate to any example folder
2. Read the `prompt.txt` file for the exact prompt to use
3. Use the prompt with GitHub Copilot Chat on the corresponding code file
4. See how Copilot responds and helps with the specific task
